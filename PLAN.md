# План Frost

Живой документ: что уже сделано, что проверить перед релизом и куда развиваться дальше.

## Цель и принципы

Frost: лёгкий и красивый музыкальный плеер для Windows с большими каталогами.

- **Работает сразу после установки**: без аккаунтов, ключей API и ручной настройки.
- **Никаких своих серверов**: Frost обращается только к источникам музыки и текстов и к GitHub.
- **Всё локально**: медиатека, настройки и история остаются на компьютере.
- **Открытый код**: GPL-3.0-or-later (этого требует RustyPipe).

## Честная оценка: чего не хватает до «законченного» плеера

Версия 0.2.0 уже удобна каждый день, но до 1.0 есть четыре пробела:

1. **YouTube ломается без обновлений.** YouTube регулярно меняет защиту, и старые версии yt-dlp перестают играть. Сейчас yt-dlp обновляется только кнопкой в настройках.
2. **Нечем разбирать жалобы.** Frost ничего не отправляет (и не должен), но и журнала ошибок у пользователя нет.
3. **Распространение.** Установщик не подписан (SmartScreen), обновление через браузер.
4. **Базовые вещи плеера для Windows.** Нет трея и мини-плеера, локальных файлов, импорта плейлистов, кроссфейда, выбора устройства вывода.

Отсюда порядок: сначала надёжность, потом Windows, потом медиатека и звук.

## Как выпускать обновления

1. Изменения копятся в разделе «Не выпущено» в `CHANGELOG.md`, CI должен быть зелёным.
2. Версия в трёх файлах (`package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`), тег `vX.Y.Z`.
3. Черновик релиза собирается сам, установщик проверяется на чистой Windows по чек-листу выше.
4. Публикация, пост в Telegram. Frost у пользователей покажет уведомление в течение суток.
5. Если YouTube перестал играть у всех, исправление выходит как `X.Y.Z+1` в тот же день.

## Риски и решения

| Риск | Решение |
|---|---|
| YouTube меняет защиту, старые yt-dlp и RustyPipe перестают играть | Автообновление yt-dlp (0.2.1), два движка страхуют друг друга, быстрые выпуски через CI |
| SoundCloud меняет `client_id` или API | `client_id` извлекается со страницы автоматически; при сбое понятная ошибка и переход на YouTube |
| Нет обратной связи о сбоях: Frost ничего не отправляет | Журнал и «Скопировать отчёт» (0.2.1), шаблоны Issues, Telegram |
| Неподписанный установщик пугает SmartScreen | Инструкция в README и описании релиза, подпись в 0.3 |
| Претензии правообладателей | Frost не хранит и не раздаёт контент, только воспроизводит открытое; дисклеймер в README |
| Эффекты окна тормозят на слабых ПК | Эффекты выключаются в настройках, учитывается системная настройка «уменьшить анимацию» |
